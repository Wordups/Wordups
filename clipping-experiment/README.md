# clip-ops

An experiment in clipping **authorized** long-form content into short-form video for paid clipping campaigns.
Goal: $0 → first cash received → $100 cumulative **net cash received** in 30 days.

- Plan and operating model: [`docs/PLAN.md`](docs/PLAN.md)
- Manual tracking templates (edit in Excel): [`data/`](data/)
- Only clip sources where `authorized_to_clip = true`. Publishing stays human-approved during the MVP.
- Any rate, fee or rule not confirmed from a primary source is `VERIFY_AT_SIGNUP` (see the Claims Register in the plan).
